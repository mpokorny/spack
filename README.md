# Spack for DSA-2000

This repository is a fork of the main
[Spack](https://github.com/spack/spack) repository, with the addition
of a submodule that adds the DSA-2000 Spack [package
repository](https://gitlab.com/dsa-2000/code/spack). Updates to this
repository, both mirroring the upstream and the submodule updates are
irregular. Eventually, we may decide to create branches and tags more
systematically, but, for now, only the "dsa2000" branch is configured
as described here.
